# Contribuir a Transformative Games

## Bienvenido 🎉

Gracias por tu interés en contribuir a este proyecto de juegos transformativos.

## 🚀 Cómo Contribuir

### Reportar Errores
1. Abre un issue en GitHub
2. Describe el problema claramente
3. Incluye pasos para reproducir el error
4. Añade capturas de pantalla si es relevante

### Sugerir Mejoras
1. Abre un issue con la etiqueta `enhancement`
2. Describe tu idea
3. Explica cómo beneficia a los usuarios
4. Proporciona ejemplos si es posible

### Enviar Código
1. Fork el repositorio
2. Crea una rama (`git checkout -b feature/AmazingFeature`)
3. Haz commit de tus cambios
4. Push a la rama
5. Abre un Pull Request

## 📋 Guía de Estilo

- Código limpio y bien comentado
- Nombres descriptivos
- Pruebas para nuevas funcionalidades
- Documentación actualizada

## 🌟 Código de Conducta

- Respeto mutuo
- Inclusión
- Comunidad positiva
- Diálogo constructivo

¡Gracias por contribuir! 💪
